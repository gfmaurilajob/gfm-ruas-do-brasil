Crie uma SPEC documental para "$ARGUMENTS" usando
`templates/specifications/specification-template.md`: status/responsável/data, contexto,
escopo e exclusões, requisitos funcionais/não funcionais com ID e critério de aceite,
dependências/licenças, arquitetura proposta, riscos, testes/validação/evidências, questões
pendentes e aprovação de requisitos. Salve em `docs/specs/`. A aprovação da SPEC NÃO autoriza
código, infraestrutura nem implantação. Não criar código/Blueprints/assets. Idioma: pt-BR.
