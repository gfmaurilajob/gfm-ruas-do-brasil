# Papéis documentais dos agentes

Os papéis servem a Codex CLI, Claude Code, GitHub Copilot CLI e OpenCode; não presumem subagentes instalados ou recursos ativos. A fonte comum é `AGENTS.md`; o orquestrador atua dentro das permissões concedidas pelo usuário e das capacidades verificadas da ferramenta.

| Papel | Responsabilidade |
|---|---|
| ARCHITECT | Limites de sistemas Unreal, C++ e decisões arquiteturais. |
| IMPLEMENTER | Implementação futura autorizada e integração dos sistemas. |
| GAMEPLAY | Personagens, veículos, missões e economia de gameplay. |
| WORLD DESIGNER | Organização regional, mapas, cenários e procedência. |
| AI DEVELOPER | Comportamento de NPCs, pedestres e trânsito. |
| TESTER | Testes automatizados, funcionais e evidências. |
| REVIEWER | Revisão de qualidade, segurança e desempenho. |
| DEVOPS | Build, automação e infraestrutura auxiliar justificada. |
| DOCS WRITER | Documentação, rastreabilidade e relatórios. |
| ORCHESTRATOR | Coordenação, dependências, permissões e consolidação de resultados. |

Um agente pode exercer múltiplos papéis; revisão independente depende de disponibilidade e autorização. Nenhum papel amplia acesso ou autoriza ações externas ou destrutivas.
