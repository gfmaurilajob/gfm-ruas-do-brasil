# Segurança

Não expor segredos ou dados pessoais; restringir permissões de ferramentas e agentes; avaliar procedência e licenças. Exemplos e testes usam dados sintéticos. Não desativar autenticação, autorização ou TLS. Nunca suprimir falhas críticas. Serviços opcionais requerem ameaça, controles e aprovação próprios. Não publicar backups nem material sem direitos verificados.
