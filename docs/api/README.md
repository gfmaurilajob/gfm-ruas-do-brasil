# Documentação de API

Somente se uma API auxiliar for necessária e aprovada, registrar contrato, versão, autenticação, autorização, entradas, saídas, erros, compatibilidade e exemplos sanitizados. Não presumir API no protótipo single-player.

OpenAPI pode ser adotado para APIs REST quando consumidores e tooling se beneficiarem. A especificação deve ser validada e sincronizada com implementação futura.
