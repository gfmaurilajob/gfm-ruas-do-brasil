# Tarefas — índice

Identificadores de tarefa são estáveis e independentes de ferramenta de IA:

`TAREFA-NNNN-descricao-curta`

Estado permitido: `PROPOSTA`, `APROVADA`, `EM ANDAMENTO`, `CONCLUÍDA`, `BLOQUEADA`, `CANCELADA`.

Cada tarefa deve citar:

- objetivo verificável;
- fontes canônicas em `docs/FONTE-UNICA-VERDADE.md`;
- critérios de aceite;
- autorização necessária;
- relatório de continuidade em `reports/`.

Nenhuma tarefa pode autorizar, por si mesma, implementação, instalação, publicação ou comando destrutivo.
