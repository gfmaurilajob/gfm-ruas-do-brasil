# Comunicação entre sistemas de gameplay

Selecionar comunicação e ciclo de vida de objetos Unreal conforme a versão adotada e os requisitos aprovados. Evitar acoplamento excessivo e dependências circulares. Eventos locais e integrações externas são decisões distintas; não introduzir serviços para uma necessidade ainda não demonstrada. Documentar falhas e testes em cada SPEC.
