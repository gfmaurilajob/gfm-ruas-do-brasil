# Mermaid

Use Mermaid para diagramas leves revisados em texto: sequência, dependências, fluxos de decisão e visão simplificada. Mermaid e Draw.io são opções para diagramas editáveis, conforme a necessidade.

Indique atores, limites de confiança e sistemas externos sem usar dados reais. O diagrama deve refletir uma especificação aprovada, não substituir a validação da implementação.
