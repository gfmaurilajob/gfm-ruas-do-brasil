# Integrações

Quando uma integração externa for necessária e aprovada, documentar contratos, autenticação, tempo limite, dados tratados, segurança, falhas e operação conforme aplicável. Não presumir serviço externo para o protótipo single-player.

Preferir OpenAPI/AsyncAPI ou esquemas apropriados quando escolhidos. Exemplos usam dados sintéticos e endpoints neutros; segredos e URLs internas nunca são incluídos.
