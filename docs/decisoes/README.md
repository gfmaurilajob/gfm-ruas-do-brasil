# Decisões técnicas — ADR

Registrar decisões arquiteturais aqui, uma por arquivo, com identificador crescente:

`ADR-0001-titulo-curto.md`

## Modelo mínimo

```text
# ADR-0000 — [título]

Status: [PROPOSTA | APROVADA | REJEITADA | SUPERADA]
Data: [AAAA-MM-DD]
Contexto: [problema e restrições]
Decisão: [o que foi decidido]
Alternativas consideradas: [opções]
Consequências: [positivas e negativas]
Autorização: [quem aprovou, se aprovada]
Referências: [caminhos canônicos]
```

Nenhuma decisão é considerada aprovada sem registro explícito de autorização. Enquanto a SPEC-001 estiver PROPOSTA, não existe arquitetura aprovada para implementação.
